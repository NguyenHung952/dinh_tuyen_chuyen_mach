## 📚 Nội dung 101 Labs

### 1.0 Network Fundamentals (Labs 1-16)

| Lab | Nội dung |
|-----|----------|
| 1-2 | Cấu hình và kiểm tra địa chỉ IPv4 / IPv6 |
| 3 | IPv6 Address Autoconfiguration & EUI-64 |
| 4 | ARP và Proxy ARP |
| 5-7 | Kết nối Serial Back-to-Back, HDLC, PPP |
| 8-10 | PPP Authentication: PAP & CHAP |
| 11 | eBGP Advanced |
| 12 | GRE Point-to-Point Tunnels |
| 13 | Power over Ethernet (PoE) |
| 14-16 | Kiểm tra IP trên Windows, Linux, Mac |

### 2.0 Network Access (Labs 17-38)

- **VLANs**: Standard, Extended, Native VLAN
- **VTP**: Server, Client, Transparent Mode
- **Spanning Tree**: Port States, Root Bridge (Manual + Macro), PortFast, RPVST+
- **EtherChannel**: Static, PAgP, LACP
- **Inter-VLAN Routing**: Router-on-a-Stick, SVI
- **CDP & LLDP**: Discovery Protocols
- **Wireless**: WAP, WLC Installation
- **Errdisable Recovery**

### 3.0 IP Connectivity (Labs 39-62)

| Giao thức | Nội dung |
|-----------|----------|
| **Static Routing** | Via interfaces, IP addresses, Named routes, Default routes, IPv6 routes, Floating routes |
| **RIPv2** | Cấu hình cơ bản |
| **OSPF** | Point-to-Point, Broadcast, Non-Broadcast, Point-to-Multipoint, Router ID, Passive Interface, Debugging |
| **EIGRP** | Basic, Wildcard masks, Auto-summarization, Passive interfaces, Route summarization, Database verification |
| **First Hop Redundancy** | HSRP, GLBP, VRRP |

### 4.0 IP Services (Labs 63-79)

| Dịch vụ | Nội dung |
|---------|----------|
| **NAT** | Static NAT, Dynamic NAT, PAT (Interface-based & Pool-based) |
| **DNS** | Cấu hình DNS trên server và host |

| **NTP** | Cấu hình NTP Client |

| **QoS** | Classification & Policy Map |
| **SSH** | Cấu hình SSH, vô hiệu hóa Telnet |
| **IOS Upgrade** | TFTP & FTP |

### 5.0 Security Fundamentals (Labs 80-108)

| Chủ đề | Nội dung |
|--------|----------|
| **Passwords** | Enable secret, Console, VTY, Password với ký tự đặc biệt |

| **AAA** | TACACS+, RADIUS |

## 🎓 Lộ trình học tập

### 1️⃣ Cài đặt và chuẩn bị
- Cài đặt Packet Tracer (miễn phí) hoặc GNS3
- Tải IOS image (nếu dùng GNS3)
- Tạo thư mục lab riêng

### 2️⃣ Bắt đầu từ Lab 1
- Làm từ đầu đến cuối, đừng bỏ qua lab nào
- Nếu bị kẹt, chuyển lab khác và quay lại sau

### 3️⃣ Kiểm tra với Solution
- So sánh cấu hình của bạn với solution
- Hiểu **tại sao** cấu hình đó hoạt động

### 4️⃣ Challenge Labs
- Sau khi hoàn thành 101 labs, thử sức với 15 Challenge Labs
- Tự cấu hình mà không cần xem solution

### 5️⃣ Ôn tập
- Lặp lại các lab với IP addressing khác
- Thêm router/switch vào topology
- Tự "break" lab và sửa chữa
